# Bean Scene — Coffee Shop Landing Page

A coffee shop landing-page study built with HTML, CSS and a small inline JavaScript scroll handler. The page brings together a product menu, brand story, promotional sections and customer feedback.

## Page sections

- Hero section and navigation.
- Coffee menu cards with product imagery and pricing.
- About and brand benefits sections.
- Promotional banner, testimonial and newsletter interface.
- Sticky-header styling triggered on scroll.

## Stack

HTML · CSS · JavaScript · Google Material Symbols

## Run locally

No package installation or build step is required. With Python 3 installed:

```bash
git clone https://github.com/Feraz-hub/bean_scene.git
cd bean_scene
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). On Windows, use `py -m http.server 8000` if `python` is not available.

## Project map

| Path | Purpose |
| --- | --- |
| `index.html` | Page sections and inline scroll behaviour |
| `style.css` | Layout, typography and visual styling |
| `img/` | Coffee imagery, icons and decorative assets |

## Scope

A visual frontend study. Ordering, sign-in and newsletter controls are demonstration interfaces without connected services. Mobile navigation behaviour, form handling and accessibility are areas for further development. Sample company details and testimonials are placeholder content.
